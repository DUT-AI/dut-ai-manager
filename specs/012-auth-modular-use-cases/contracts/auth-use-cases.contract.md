# Contract: Chữ Ký Giao Tiếp Của Các Auth Use Cases

**Feature**: `012-auth-modular-use-cases` | **Date**: 2026-10-17

Mọi signature của phương thức `execute` và `__init__` của các lớp use case dưới đây được giữ nguyên 100% để đảm bảo tương thích tuyệt đối với Dishka Provider và Controller:

```python
class BaseAuthUseCase:
    def __init__(self, account_repo: AccountRepository, user_repo: UserRepository): ...
    def create_tokens(self, user: UserEntity) -> tuple[str, str]: ...

class AuthenticateUseCase(BaseAuthUseCase):
    def execute(self, email: str, password: str) -> tuple[UserEntity, str, str]: ...

class AuthenticateZaloPhoneUseCase(BaseAuthUseCase):
    def execute(self, zalo_phone_token: str, zalo_user_id: str, access_token: str) -> tuple[UserEntity, str, str]: ...

class RefreshTokenUseCase(BaseAuthUseCase):
    def execute(self, refresh_token: str) -> tuple[str, str]: ...

class GetMeUseCase:
    def __init__(self, user_repo: UserRepository): ...
    def execute(self, user_id: int) -> UserEntity: ...

class ChangePasswordUseCase(BaseAuthUseCase):
    def execute(self, user_id: int, old_password: str, new_password: str) -> None: ...

class CreateAccountUseCase:
    def __init__(self, account_repo: AccountRepository, user_repo: UserRepository): ...
    def execute(self, user_id: int, password: str) -> Account: ...

class ForgotPasswordUseCase(BaseAuthUseCase):
    def __init__(self, account_repo: AccountRepository, user_repo: UserRepository, event_bus: EventBus): ...
    def execute(self, email: str) -> None: ...
```
